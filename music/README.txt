Put your background song here (for example: our-song.mp3).

Then open js/content.js and set:

  music: {
    file: "music/our-song.mp3",
    volume: 0.35,
  },

If "file" is left empty, the site plays a soft built-in music-box melody instead.
MP3 works in every browser. Keep the file small (around 3-5 MB) so it loads fast.
